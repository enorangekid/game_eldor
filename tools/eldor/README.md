# 엘도르 스크립트 도구

`*_script.md`(엘도르 연대기 스크립트)를 읽어서 **분기를 검사하고 분기도를 그리는** 도구입니다. 스크립트는 지금처럼 마크다운으로 쓰고, 도구는 읽기만 합니다. Node만 있으면 되고 설치할 것은 없습니다.

```
node tools/eldor/check.js            검사 (오류가 있으면 종료 코드 1)
node tools/eldor/check.js --quiet    오류·주의만
node tools/eldor/map.js --open       분기도 만들고 브라우저로 열기
node tools/eldor/map.js --watch      스크립트를 고칠 때마다 분기도 다시 만들기
```

분기도는 `tools/eldor/out/eldor_map.html` 한 장으로 만들어집니다. 인터넷 없이 더블클릭으로 열리고, 저장소에는 올리지 않습니다(`.gitignore`). 주소 끝에 `#E1-08`처럼 장면 ID를 붙이면 그 장면이 선택된 상태로 열립니다.

## 파일

| 파일 | 역할 |
|---|---|
| `parse.js` | 스크립트 파서. 장면·선택지·변수 변경·조건·이동·조사를 구조로 읽는다. 기본 대상 파일 목록(`DEFAULT_FILES`)도 여기 — **새 막 스크립트가 생기면 여기에 추가** |
| `check.js` | 검사기. 분기도에도 결과가 들어간다 |
| `map.js` + `map_template.html` | 분기도 생성기와 화면 틀 |

## 읽는 표기 (프롤로그 스크립트 '표기 규칙'과 같음)

| 표기 | 도구가 읽는 것 |
|---|---|
| `### P-01 제목` / `#### P-07A 제목` | 장면 / 하위 장면. ID 없는 `#### 언덕 위`는 장면 안 구획 |
| `> 배경: … · 등장: … · 진입: …` | 장면 정보. `진입`에 적힌 장면 ID는 실제 이동과 대조한다 |
| `? 선택 …` / `? 추리 …` + `  1) ★ 보기` | 선택지·추리와 보기 (★ = 원고 경로) |
| `→ \`변수\` +1, \`변수\` = 값` | 변수 변경 (줄이 `→`로 시작할 때만) |
| `[if \`변수\` ≥ 2] … [else] … [end]` | 조건 (`=` `≠` `≥` `≤`) |
| `⇒ P-02` | 이동. ID가 없으면(`⇒ 1막 계속 — …`) '열린 끝' |
| `@조사 …` + `- **항목**` | 조사 지점 |
| `**변수 기본값:** \`x\` 0 · …` / `**… 넘어오는 변수:** …` | 파일 머리말의 변수 선언 |

## 검사 항목

- **오류** — 장면 ID 중복 · 없는 장면으로 이동 · ⇒ 이동이 없는 장면 · `[if]`/`[else]`/`[end]` 짝 · 어디서도 정하지 않은 변수를 조건에서 읽음
- **주의** — 시작에서 닿을 수 없는 장면 · 이동 없이 끝나는 선택지 보기 · 보기가 하나뿐인 선택지 · 넣은 적 없는 값과 비교 · 그 시점에 절대 참이 될 수 없는 숫자 조건 · `진입`과 실제 이동이 다름 · '넘어오는 변수'가 앞 막에 없음
- **참고** — 정해 놓고 읽지 않는 변수(다음 막용일 수 있음) · 기본값 선언이 없는 변수 · `= 값` 비교인데 값이 더 커질 수 있음 · 앞 막 변수인데 '넘어오는 변수' 목록에 없음 · 열린 끝

숫자 조건 검사는 시작부터 모든 경로를 따라 변수의 최소~최대 값을 계산해서 판단합니다. 선택지의 보기끼리는 하나만 고른다고 보고, `[if]` 안의 변경은 일어날 수도 안 일어날 수도 있다고 봅니다.
